# レヴィン行動理論による特性診断

心理学者クルト・レヴィンの行動方程式 **B = f(P, E)**（行動は、その人と環境の両方で決まる）にもとづいて、自分を動かしている「本人の側の力」と「環境の側の力」を21項目で測定し、行動特性と変化への向き合い方を振り返るセルフチェックツールです。

**→ [ツールを開く](https://m1m2carbine-source.github.io/lewin-behavior-diagnostic/)**

## これは何か・何でないか

- 標準版132問／短縮版66問／スクリーニング版21問の3つの版があり、いずれも所要時間3〜30分程度です。
- 回答・結果はすべてこの端末・このブラウザの中だけで処理されます。**外部のサーバーに送信されることは一切ありません。**
- 学術的に検証された心理検査ではなく、統計的な妥当性・信頼性の検証（因子分析等）は行っていません。病気の診断、向き不向きの判定、採用や人事評価には使わないでください。
- 何を測れていないか（母集団との比較がないこと、21尺度の因子構造が未検証であることなど）は、診断結果画面自体にも明記しています。
