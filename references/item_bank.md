## 1. 構成の考え方

レヴィンの基本公式 **B = f(P, E)**（行動は人と環境の関数）を診断の骨格に据える。
P（個人）とE（環境）を独立に測り、その両者が交差する場面としてC（葛藤）を、
時間軸上の変化としてF（力の場・崩す／動かす／固める）を、対人的な場としてG（集団力学）を測る。

| 領域 | 理論的出典 | 下位尺度数 | 項目数 |
|---|---|---|---|
| P 個人 | 緊張系・準欲求、要求水準研究、心理的分化 | 5 | 30 |
| E 環境 | 誘発性（valence）、障壁、生活空間の構造 | 4 | 24 |
| C 葛藤 | 葛藤の3類型＋二重接近-回避型 | 4 | 20 |
| F 力の場 | 力の場分析、3段階変革モデル | 4 | 24 |
| G 集団 | 集団規範・集団決定、リーダーシップ風土、境界人 | 4 | 22 |
| V 妥当性 | 反応バイアス統制 | 3 | 12 |
| **計** | | **21＋3** | **132** |

各下位尺度は5〜6項目で構成し、うち約1/3を逆転項目とする。
これは「はい方向にそろえる」回答傾向（黙従バイアス）を打ち消し、
尺度得点の分散を確保して定量的な比較を可能にするための設計である。

## 2. 回答形式

### 6件法（G3以外の126問）

| 選択 | 表示 | 素点 |
|---|---|---|
| 1 | まったく当てはまらない | 1 |
| 2 | ほとんど当てはまらない | 2 |
| 3 | あまり当てはまらない | 3 |
| 4 | やや当てはまる | 4 |
| 5 | かなり当てはまる | 5 |
| 6 | 非常に当てはまる | 6 |

中間選択肢を置かない偶数件法を採用する。中間に逃げられないため、
各項目が必ず方向をもった情報を返し、尺度得点の弁別力が上がる。

**逆転項目（末尾に【R】と表記）の換算**：`換算値 = 7 − 素点`

### 3肢強制選択（G3の6問）

各問について、a／b／cのうち最も自分に近いものを1つだけ選ぶ。
a＝専制型、b＝民主型、c＝放任型に対応し、選択比率をプロファイルとして算出する。

## 3. 領域P：個人（内的な力の構造）30問

### P1　緊張系持続性（未完了課題の心理的残留）

理論背景：レヴィンの緊張系（tension system）と準欲求。目標が未達成のあいだ心的緊張は
解消されず、行動を駆動し続ける。ツァイガルニク効果はその実験的裏づけ。

| No | 項目文 | R |
|---|---|---|
| P1-1 | 途中で中断した作業のことが、別のことをしている間も繰り返し頭に浮かぶ。 | |
| P1-2 | 未完了の案件があると、休日でも気持ちが完全には切り替わらない。 | |
| P1-3 | 一度着手したことは、区切りがつくまで落ち着かない。 | |
| P1-4 | やりかけの用件を思い出して、夜中や早朝に目が覚めることがある。 | |
| P1-5 | 締め切りまで日数があっても、着手した案件は常に意識の片隅にある。 | |
| P1-6 | 処理していない用件があっても、特に気にならない。 | R |

高得点＝緊張系が持続しやすい（推進力になる一方、心的負荷が滞留しやすい）

---

### P2　要求水準の高さ

理論背景：要求水準（level of aspiration）の研究。概念の初出はホッペ（1930）・デンボ（1931）、
体系化は Lewin, Dembo, Festinger & Sears（1944）。
人は次の行為に先立って達成目標の高さを設定し、それが行動量を規定する。

| No | 項目文 | R |
|---|---|---|
| P2-1 | 目標を立てるとき、確実に届く水準よりやや上を設定する。 | |
| P2-2 | 「できて当たり前」の水準を、周囲より高く見積もっているほうだ。 | |
| P2-3 | 平均的な出来では、自分としては不十分だと感じる。 | |
| P2-4 | 最初から確実に達成できる範囲に目標を抑えることが多い。 | R |
| P2-5 | 一度達成した水準は、次はさらに上げないと満足できない。 | |
| P2-6 | 自分に課す基準は、周囲が求める基準より厳しい。 | |

高得点＝要求水準が高い

---

### P3　成功接近／失敗回避の極性

理論背景：要求水準研究から派生した「成功への接近」と「失敗の回避」という
二つの力のベクトル。同じ目標場面でも、どちらの力が優勢かで行動が変わる。

| No | 項目文 | R |
|---|---|---|
| P3-1 | 難しい課題ほど、やってみたいと感じる。 | |
| P3-2 | 挑戦の場面では、まず「成功したときの成果」を思い描く。 | |
| P3-3 | 失敗の可能性が頭をよぎると、着手をためらう。 | R |
| P3-4 | 結果が読めない仕事より、確実に無難にこなせる仕事を選ぶ。 | R |
| P3-5 | 評価される場面では、緊張よりも意欲が上回る。 | |
| P3-6 | 恥をかくことを避けるために、目立つ役割を辞退することがある。 | R |

---

### P4　目標乖離への調整（要求水準の可動性）

理論背景：要求水準研究（Lewin, Dembo, Festinger & Sears 1944）。
成功を重ねると水準が上がることは明確に示されたが、失敗の効果はより複雑である。
失敗が続くと、成功が確実な位置まで下げるか、届かないのが当然なほど高く掲げるかの
どちらかに逃げる。本尺度はこの「結果に応じて水準を動かせるか」を測る。
詳細は theory.md 第2節を参照。

| No | 項目文 | R |
|---|---|---|
| P4-1 | うまくいったときは、次の目標を少し上げる。 | |
| P4-2 | 失敗したときは、いったん水準を下げて足場を固め直す。 | |
| P4-3 | 結果が悪くても、同じ高さの目標に固執してしまう。 | R |
| P4-4 | 一度の失敗で、目標を大幅に引き下げてしまう。 | R |
| P4-5 | 実績と目標の差を、数値や具体的な事実で確認してから次を決める。 | |
| P4-6 | 成功しても目標は変えず、同じ水準を繰り返すことが多い。 | R |

高得点＝要求水準の調整が柔軟かつ現実的

---

### P5　心理的分化と境界の透過性

理論背景：生活空間は複数の領域に分化し、領域間には境界がある。
境界が硬すぎれば切り替えができず、緩すぎれば一領域の緊張が全体に波及する。

| No | 項目文 | R |
|---|---|---|
| P5-1 | 仕事、家庭、趣味など、場面ごとに気持ちを切り替えられる。 | |
| P5-2 | 一つの領域の不調を、他の領域まで引きずることは少ない。 | |
| P5-3 | 役割が変わると、自分の振る舞いも自然に変わる。 | |
| P5-4 | 職場での出来事を、家に帰っても引きずってしまう。 | R |
| P5-5 | 自分の中で「これはこれ、それはそれ」と線を引くのが得意だ。 | |
| P5-6 | どの場面でも同じ調子で振る舞い、切り替えは苦手だ。 | R |

高得点＝領域が適度に分化し、境界の開閉を制御できている

## 6. 領域F：力の場（変化への構え）24問

理論背景：力の場分析（force field analysis）では、現状は推進力と抑制力が
釣り合った「準定常的均衡」として捉えられる（Lewin 1947/1951）。
なお変化の3段階について、レヴィン自身が書いたのは Unfreezing / Moving / Freezing であり、
「再凍結（refreezing）」の語は使っていない。詳細は theory.md 第4-3節を参照。

### F1　自分から動き出す力（推進力の生成）

|---|---|---|
| F1-1 | 現状に問題があれば、自分から動き出す。 | |
