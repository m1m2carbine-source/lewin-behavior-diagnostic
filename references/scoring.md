## 1. 素点の算出

### 手順

1. 逆転項目（【R】）は `7 − 素点` に換算する
2. 下位尺度ごとに換算後の値を平均する → **尺度平均**（1.00〜6.00、小数第2位まで）

### 欠測の扱い

**その尺度の設問のうち3分の1を超えて欠測なら、測定不能とする。**
絶対数（2問以上など）で決めると、版によって1尺度あたりの問数が違うため
扱いが揺れる。比率にすれば標準版（6問中3問以上）と短縮版（3問中2問以上）で
同じ基準になる。

### G3（選択式）の扱い

尺度平均は出さない。a／b／cの**選択数**を数える。
6問しかないため百分率は16.7%刻みでしか動かず、精度を偽装するので件数を主に示す。

d（この場面を経験したことがない）は集計から除く。
**dが3問以上なら、人の動かし方の判定そのものを出さない。**
経験のない場面を想像で答えた回答から型を出しても意味がないため。

## 2. 中点スコアへの換算

### 換算式

```
中点スコア = 50 + 10 × (尺度平均 − 3.50) ÷ 0.85
```

- 3.50 は6件法の理論的中点
- 0.85 は6件法自己記入式尺度における一般的な尺度内標準偏差の想定値
- 算出結果は 20〜80 の範囲に丸める
- 呼称は「T得点」を使わない。規範集団に基づく標準得点の用語であり、規範なしに使うと誤読される

**この換算は規範集団のデータに基づくものではない。**
実際の集団平均・標準偏差を用いた基準値ではなく、理論的中点を基準に置いた
暫定的な位置づけであることを、結果表示の際に必ず明記する。
臨床検査でいえば、外部精度管理を経ていない自家調製標準品のような状態にあたる。

### 解釈区分

規範集団を持たないため、母集団と比べた高低は言えない。
言えるのは理論的中点（3.50＝スコア50）からの隔たりだけなので、
判定語も母集団比較を思わせない書き方にする。
呼称も「T得点」ではなく**中点スコア**とする。T得点は規範集団に基づく
標準得点を指す確立した用語であり、規範なしに使うと誤読される。

| 中点スコア | 表記 | 意味 |
|---|---|---|
| 70以上 | 中点よりかなり上 | その特性が行動を強く動かしている |
| 60〜69 | 中点より上 | 傾向としてはっきり出ている |
| 40〜59 | 中点に近い | 状況によって変わる |
| 30〜39 | 中点より下 | 反対方向がやや優勢 |
| 30未満 | 中点よりかなり下 | 反対方向の特性が行動を動かしている |

境界は 30/40/60/70。20000人規模のモンテカルロ検証で、
この境界だと両端の出現率がそれぞれ約6%に収まることを確認している
（従来の 35/45/56/65 では両端が14%前後に膨らみ、「非常に高い」が乱発された）。

**両極性の項目には、この判定語を使わない。**
「目標水準の置き方 ／ 中点よりかなり下」では意味を成さないため、
極ラベルを使って「「届く範囲に置く」に強く寄る」と書く。

## 3. 導出指標（6種）

すべて本ツールが構成したもので、レヴィン本人の指標ではない。

### 指標1　自分基準で動くか、状況で動くか

```
PE差 = mean(中点スコア: P1..P5) − mean(中点スコア: E1, E2, E4)
```

- +1.5以上：自分の基準が優位
- −1.5〜+1.5：ほぼ同程度
- −1.5以下：環境の条件が優位

E3（迂回路を見つける）は能力系のため、E側から外す。

以前は `P平均 ÷ (P平均 + E平均) × 100` という比率だったが、
分子と分母が同じ1〜6の尺度に載るため値が50に強く引き寄せられ、
境界帯が約半数を占めた。中点スコアの差に変えて約24%まで下げている。

**限界**：E領域の項目は環境そのものではなく「環境をどう感じるか」を測っている。
感じ方も本人の特性なので、この指標はPとEを完全には切り分けていない。

### 指標2　着手する力と定着させる力

```
FFB = mean(F1, F3) − F4
```

- +0.15以上：着手が優位／−0.15〜+0.15：ほぼ均衡／−0.15以下：定着が優位

F2（反対を察知する）は保持側に入れない。反対の察知は変化を妨げる力ではなく、
変化を成功させる対処能力であり、保持側に数えると変革に長けた人ほど
「定着が優位」と誤判定される。F2は指標3として独立させる。

### 指標3　抵抗への備え

F2 の素点をそのまま示す。

### 指標4　迷う場面での決断力

```
CTI = mean(C1, C2, C3, C4)
```

最も弱い型は、2位との差が0.5未満なら特定しない。
模擬回答で差が0.2未満の受検者が2割程度おり、僅差での断定は誤解を招く。

### 指標5　目標の置き方

P2（高さ）とP4（修正のしやすさ）の組み合わせ。境界は素点3.50。

| | P4 高 | P4 低 |
|---|---|---|
| **P2 高** | 高く設定し、修正もできる | 高く設定するが、修正できない |
| **P2 低** | 堅実に設定し、修正もできる | 低い水準に固定している |

右側の2つは、要求水準研究で知られる2つの不適応パターン
（届かないのが当然な高さに逃げる／成功が確実な低さに逃げる）に対応する。

### 指標6　仕事の持ち帰りやすさ

```
TLI = P1 − P5
```

+1.0以上で持ち帰りが多い、−1.0以下で切り替えが速い。

### 廃止した3つの指標

以前は9つあったが、式の上で重なっているものを外して6つにした。
尺度どうしを独立に生成した模擬データで、構造的な相関だけを測って判断している。

| 廃止した指標 | 重なっていた相手 | 相関 | 扱い |
|---|---|---|---|
| 変革を担う力（F1〜F4の平均） | 抵抗への備え（F2そのもの） | +0.51 | 廃止。F1・F3・F4は着手差が使っている |
| 誘因設計の効きやすさ（E1−P群） | PE差 | −0.59 | PE差の「環境側の内訳」として表示 |
| 障害除去の効きやすさ（E2−P群） | PE差 | −0.59 | 同上 |

合意して決める力（G2）と迂回路を見つける力（E3）は、変化の成否に効くが
高低に優劣がないため、指標に合算せず補助情報として並べる。

## 4. 基本4類型の判定

**軸1**：PE差（0を境界、±1.5未満は中立）
**軸2**：着手と定着の差 FFB（0を境界、±0.15未満は中立）

| | 着手が優位（FFB > 0） | 定着が優位（FFB ≤ 0） |
|---|---|---|
| **自分の基準が優位（PE差 > 0）** | **自ら動き出す型**（最初の一人） | **決めたことを守り抜く型**（守り手） |
| **環境の条件が優位（PE差 ≤ 0）** | **仕組みを組み替える型**（仕掛け人） | **場に合わせて回す型**（調整役） |

どちらかの軸が中立圏内なら「境界帯」とし、型を断定しない。

### 型は入り口であって、結論ではない

**この4分類は、レヴィン自身の方法論と衝突する。**
Lewin (1931) は「現代の量的物理学では、二分法的な分類は連続的な段階づけに
完全に置き換えられた」と書き、心理学もカテゴリー的（アリストテレス的）思考から
連続量と力による記述（ガリレイ的思考）へ移るべきだと主張した。
本ツールが葛藤の3類型の出典としている論文が、まさにその論文である。

実測でも同じ問題が出る。同じ人が2回受けた場合を模擬計算した結果は次のとおり。

| 測るもの | 結果 |
|---|---|
| PE差・着手差（連続値）の再検査相関 | 0.891 |
| 各軸の符号一致 | 約85% |
| **4類型の一致** | **72.4%** |
| 2値化による情報損失 | 約36% |

連続値は安定しているのに、切った瞬間に72%まで落ちる。
情報損失36%は、Bess & Harvey (2002) がMBTIで報告した26〜32%と同程度である。

したがって**型は入り口のラベルとして扱い、位置（連続値）を先に示す。**
結果画面でも、呼び名より前に2本の軸の位置を出し、
「位置のほうが本体で、呼び名は入り口」と明記している。
±1.5／±0.15 は、20000人規模のモンテカルロ検証で境界帯の発生率が
約24%に収まるよう校正した値（変更前は約49%が中間型になっていた）。

### 型は言い渡さず、本人に確かめてもらう

「あなたは調整力があります」のような文は誰にでも当てはまるため、
外れていても読み手が気づけない（バーナム効果）。
フォアラーの結論は「感じられる正確さを妥当性の証拠にしてはならない」。

そこで型ごとに**観察できる出来事**を3つ示し、
0〜1個しか当てはまらなければ判定が外れていると明示する。
これは正式なMBTIが専門家との対話で行う「ベストフィットタイプの確認」を、
ひとりでもできる形にしたもの。

### 組む相手

好みではなく2軸の構造から決まる。
**着手／定着の軸が反対の型**が、その人に欠けやすい工程を持っている。

| 型 | 抜けやすい工程 | 組むとよい相手 |
|---|---|---|
| 自ら動き出す型 | 始めたことを記録や仕組みに残す | 決めたことを守り抜く型 |
| 決めたことを守り抜く型 | 古くなったやり方を自分から壊す | 自ら動き出す型 |
| 仕組みを組み替える型 | 場が変わってもぶれない基準を持つ | 場に合わせて回す型 |
| 場に合わせて回す型 | 自分が変化の口火を切る | 仕組みを組み替える型 |

**入れてはいけないもの**：同じ型の有名人、型別あるある、相性ランキング、適職判定。
自己判定による型分けは自己理解を固定し、他者へのラベリングから分断を招く。
また型と職業の相関は、誰がどこで活躍するかを予測できるほど強くない。

## 5. 妥当性判定

結果を読む前に確認する。**標準版でしか項目数が足りない項目がある。**

| 指標 | 算出 | 基準 | 実施する版 |
|---|---|---|---|
| 社会的望ましさ | V1 6項目の**平均** | 4.50以上で警告 | 標準版のみ |
| 反応一貫性 | 対項目6組の絶対差の平均 | 1.50以上で警告 | 標準版のみ |
| 反応固定化 | 6件法全項目の標準偏差 | 0.60以下で警告 | スクリーニング版以外 |

合計ではなく**平均**で判定する。合計だと項目数に依存し、
短縮版（V1が2問）で3倍して当てはめると1問の誤差が3倍に増幅される。
そのため短縮版・スクリーニング版では、社会的望ましさと一貫性の判定を出さない。

1つ該当 → 結果は「参考値」として提示する。
**2つ以上該当 → 詳しい結果を表示しない。** 回答データの保存と再実施の案内だけを出し、
「警告を理解したうえで結果を見る」ボタンを押した場合にのみ表示する。
信頼できない回答から断定的な自己像を渡すと実害が出るため。

## 6. B = f(P, E) 個別式の書き下し

その人固有の行動方程式を1つの文章として書く。
ただし**この章は結論ではなく、打ち手の根拠**という位置づけになった。
結論は冒頭の「ひとことでいうと」と「まず何をするか」に置く。

**書式**：

```
あなたの行動 B は、次のように書ける。

B = f(P, E)   （行動は、その人と環境の両方で決まる）

P＝あなたという人
　P領域5項目のうち、上位2つと最も低い1つで書く

E＝あなたから見えている環境
　E1・E2・E4 のうち最も高いもので書く（E3は能力系なので使わない）

2つのつながり方
　PE差と着手・定着の差から、どちらに手を入れるほうが効くかを1〜2文で書く
```

### 書くときの決まり

- **両極性の項目は、その人がいる側の極で書く。**
  「未完了の残りやすさ」ではなく「未完了が残り続ける」「切り替えが速い」と書く。
  次元名のままでは、どちら寄りなのかが文から読めない
- **両極性の項目を「低い＝妨げ」と書かない。**
  「届く範囲に置くが低く、妨げになっています」は二重に誤り。
  低い側の極が持つ特性を、欠点として提示してしまう
- P領域の上位と下位の差が10点未満なら、突出した力はないものとして書く

**記述例**：

> あなたを主に動かしているのは、**未完了が残り続ける**（スコア77.4）と
> **失敗回避を優先**（スコア44.1）です。
> いっぽう**目標水準の置き方**は「届く範囲に置く」に寄っています（20.6）。
> これは不足ではなく、もう一方の側の特性です。
>
> 環境の側では**明確な手順を求める**（67.6）が最も強く働いています。
> この感じ方が、あなたにとっての場の見え方を決めています。
>
> 「自分基準で動くか、状況で動くか」の差は −2.1 でした。
> あなたは自分の中の基準よりも、その場の条件に合わせて動くほうです。
> そこに「着手する力と定着させる力」の差 −0.8（定着が優位）を重ねると、
> あなたの行動を最も大きく変えるのは、自分に言い聞かせることよりも
> **「置かれる場をどう組み替えるか」**のほうです。
